DraftYak

DraftYak is an open-source (Apache-2.0) project to build a local-first inbox in which AI drafts replies and nothing is sent without your explicit approval.

It is in early development: there is no release to download and no hosted service. The source code is public at github.com/draftyak/draftyak.

Google test app

DraftYak S8 spike is a test app for a one-off compatibility test of how Gmail behaves. Only the project's developer uses it, with one throwaway Gmail account. It is not a product and is not offered to anyone else.

Read the privacy policy to see what the test reads, where that stays and when it is deleted.
