WebOTP test

This page checks whether your browser can return a one-time code from a test SMS. It sends no text message and never asks for a phone number. Use a made-up code, never an account or sign-in code.

Before starting

Open https://draftyak.com/webotp/ directly on the receiving phone. Select Start before the planned test SMS is sent from the other phone. If the browser asks to share the code with this site, you can accept or decline.

In that test SMS, replace CODE in both places below with the same fresh six made-up digits. Keep the domain line last, with one space before #; do not add a URL scheme, path or another line.

DYTEST-Your code is CODE

@draftyak.com #CODE

The page has a two-minute timeout. Cancel stops the request. It shows only a fixed result, never the code. It does not authenticate an account or check whether the code matches an expected value.

Nothing has started. JavaScript and a browser with WebOTP support are required.

The page uses no cookies, storage or analytics. Its script sends no network requests. It drops its references to a returned code when the request finishes. Privacy policy.

Technical references: Chrome WebOTP documentation and the origin-bound SMS format.
